# motoilanlari-app-admin

Motoilanlari mobil uygulaması için geliştirilmiş yönetim panelidir. Admin kullanıcıları bu panel üzerinden ilanları görüntüleyebilir, durumlarını yönetebilir, ilan detaylarını inceleyebilir ve temel kullanıcı/ilan istatistiklerini takip edebilir.

## Kısa Özellik Özeti
- Firebase Authentication ile admin giriş yönetimi
- İlan listeleme, filtreleme, arama ve durum güncelleme
- İlan detay modalı ve ilan silme işlemleri
- Dashboard üzerinde kullanıcı ve ilan istatistikleri

## Kullanılan Teknolojiler
- **Next.js 15** (App Router)
- **React 19** + **TypeScript**
- **Firebase** (Auth, Firestore, Realtime Database, Storage)
- **Tailwind CSS**
- **Font Awesome**
